VibeRedesign

One site, three vibes.

A design experiment: the exact same content from Home and Resume, reimagined in three radically different visual directions. Each vibe keeps Home and Resume as separate pages, just like the original site. Pick a vibe and take it for a spin — each one links back here.

Ground Rules

Every design below is fully self-contained: no webfonts, no CDNs, no third-party requests of any kind. Just HTML, CSS with system font stacks, and vanilla JavaScript. Same content, three personalities.
