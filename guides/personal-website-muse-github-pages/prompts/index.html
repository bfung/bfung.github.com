More ideas & prompts

Companion to Publish and maintain a personal website using Muse from Meta and GitHub Pages for free

Every entry below is a real idea I had while building this site, the gist of the prompt I gave Muse, and where it landed. Steal the pattern: describe what you want, give an example or two, and let the AI do the typing.

Idea
A single source of truth for all my projects, with filtering and sorting.
Prompt
“Consolidate my projects into one projects.json data file, newest first. Home shows the 6 newest cards with a ‘View all’ link, and build a /projects/ page with tag filter chips and Newest/Oldest/A–Z sorting that works without JS.”
Result
Projects
Idea
A proper mobile nav that degrades gracefully.
Prompt
“Collapse the header nav into a hamburger menu under 640px that closes on link tap, Escape, or outside tap. With JS disabled the links should just render as a stacked list — desktop untouched.”
Result
Home (shrink your browser window to see the mobile menu)
Idea
Hero copy that captures my personality in wordplay.
Prompt
“Replace my homepage hero copy with my taglines — the B-line all b-words, the F-line all f-words — and tighten the spacing underneath.”
Result
Home
Idea
Never ship a stale CSS/JS file after a push again.
Prompt
“Add cache-busting to my build: append a content-hash ?v= query string to every local CSS and JS URL so browsers always fetch the fresh copy.”
Result
Home (view source and look for the ?v= hashes)
Idea
SEO and accessibility baseline across the whole site.
Prompt
“Do the SEO and accessibility quick wins: favicon, OG and Twitter cards, canonical URLs, JSON-LD Person markup, a sitemap.xml, a custom 404 page, a skip-to-content link, and no mixed-content social links.”
Result
Home
Idea
A minimalist redesign variant — a single 660px near-monochrome column.
Prompt
“One of the redesign variants should be ultra-minimal: a narrow centered column, near-monochrome palette, system fonts, nothing flashy — let the content do the work.”
Result
Minimalist variant

Neo-brutalist variant
